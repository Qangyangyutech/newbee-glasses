# 成本、定价与毛利

三档机型的账只有一处源头：[`sku/tiers.json`](../sku/tiers.json)。BOM 逐项列出，
合计必须等于该档的完全成本，任何一项对不上，`tools/tier_cost.py --check` 会直接
报错。

```bash
python tools/tier_cost.py            # 三档对比表
python tools/tier_cost.py --check    # 只校验，失败返回 1
python tools/tier_cost.py --vat 0.06 # 换一个增值税率
```

## 口径

- **完全成本**：物料 + 制造 + 包装 + 物流 + 研发摊销 + 渠道售后 + 税费。不含
  营销费用与公司管理费。
- **售价**：含税零售价。
- **增值税**：按销售环节计征，默认 13%；毛利率一律按不含税收入计算。

```
单台毛利 = 售价 × (1 − 增值税率) − 完全成本
毛利率   = 单台毛利 ÷ (售价 × (1 − 增值税率))
保本销量 = 年度固定费用 ÷ 单台毛利
```

## BOM 构成（元）

| 项目 | NB-L1 Air | NB-S1 NewBee | NB-P1 Pro |
| --- | ---: | ---: | ---: |
| 主板（SoC + 存储 + 电源） | 520 | 620 | 780 |
| 光学模组 | — | 980 | 1,850 |
| 摄像头 | 130 | 150 | 280 |
| 音频 | 60 | 110 | 160 |
| 结构件 | 180 | 320 | 720 |
| 电池 | 90 | 140 | 200 |
| 制造 | 420 | 520 | 680 |
| 包装 | 100 | 120 | 160 |
| 物流仓储 | 150 | 180 | 220 |
| 研发摊销 | 300 | 380 | 450 |
| 渠道售后 | 250 | 330 | 380 |
| 税费损耗 | 300 | 350 | 320 |
| **合计** | **2,500** | **4,200** | **6,200** |

光学模组是成本台阶的主因：Air 没有这一项，Standard 为它多付 980，Pro 的全彩
模组要 1,850——单这一项就占了 Pro 成本的 30%。

## 毛利（增值税 13%）

| 机型 | 售价 | 单台毛利 | 毛利率 | 保本销量* |
| --- | ---: | ---: | ---: | ---: |
| NB-L1 Air | 3,499 | 544 | 17.9% | 4,963 |
| NB-S1 NewBee | 6,999 | 1,889 | 31.0% | 1,430 |
| NB-P1 Pro | 11,999 | 4,239 | 40.6% | 637 |

\* 保本销量按年度固定费用 270 万（研发摊销 + 营销 + 折旧）估算，示例口径，
换自己的数用 `--fixed`。

一台 Pro 的单台毛利约等于 7.8 台 Air。**只要产能是瓶颈，高端就是唯一正确的
选择**——同样的工时，做 Pro 和做 Air 的产量差不多，毛利差近八倍。

## 增值税敏感性

| 机型 | 增值税 0% | 6% | 13% |
| --- | ---: | ---: | ---: |
| Air | 28.6% | 24.0% | 17.9% |
| NewBee | 40.0% | 36.2% | 31.0% |
| Pro | 48.3% | 45.0% | 40.6% |

税率每变动 1 个百分点，单台毛利变化约等于售价的 1%：Air 约 35 元、NewBee 约
70 元、Pro 约 120 元。定价时按 13% 算，实际税率更低的部分就是安全垫。

## 价格阶梯检查

判断「三档是否拉开」，比的不是绝对价差，而是**售价倍率有没有超过成本倍率**。

| 阶梯 | 成本倍率 | 售价倍率 | 结论 |
| --- | ---: | ---: | --- |
| Air → NewBee | 1.68× | 2.00× | 通过 |
| NewBee → Pro | 1.48× | 1.71× | 通过 |
| Air → Pro | 2.48× | 3.43× | 通过 |

只要某一档的售价倍率低于成本倍率，那一档的毛利就会被成本吃掉——`--check`
会直接把这种情况判为失败。

## 中档是夹心层

NewBee 的成本是 Air 的 1.68 倍，售价只有 2.00 倍，毛利从 17.9% 拉到 31.0%，
看起来成立；但它同时被两头挤压：

- 往上：Pro 的毛利 40.6%，同样的销售动作更值得做；
- 往下：Air 靠 3,499 的价格带走价格敏感用户，NewBee 抢不到。

所以三档不是「高中低都要卖」，而是**默认主力 + 一个价格触角 + 一个天花板**。
如果某一财年产能吃紧，先砍 NewBee 的排产，把产线让给 Pro。

## 改价流程

1. 改 `sku/tiers.json` 里的 `price` 或 `bom`；
2. 跑 `python tools/tier_cost.py --check`，把 BOM 与成本对平、把阶梯校验跑过；
3. 跑 `python -m unittest discover -s adapter/tests`，确认机型能力表没被带歪；
4. 同步 `firmware/src/tier.c` 与 `sdk/src/newbee_model.c` 里的能力字段（三处
   一致性由上面的测试守住）。
