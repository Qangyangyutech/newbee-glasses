# 架构说明

```
摄像头 / 6 麦阵列 / IMU / 环境光
            │
            ▼
┌───────────────────────────────┐
│ firmware：采样 · 唤醒 · 渲染   │  端侧
└───────────────┬───────────────┘
                │ 事件流（注视 / 手势 / 语音文本）
                ▼
┌───────────────────────────────┐
│ adapter：场景路由 · 上下文压缩 │  端侧或边缘
└───────┬───────────────┬───────┘
        │ 命中离线       │ 需要推理
        ▼               ▼
  本地动作（12 条）  DeepSeek V4-pro 专属实例（云）
                        │
                        ▼
                 字幕 / 翻译 / 导航 / 拍摄
```

## 设计取舍

- **唤醒不放云**：一次网络往返就是 200 ms 起，唤醒必须端侧完成。
- **视觉只传 ROI**：整帧上传的带宽与隐私成本都不可接受，裁剪后上传量下降约 72%。
- **离线兜底**：断网时仍保留 12 条高频指令，保证“抬起眼镜就能用”。

## 时延口径

端到端时延 = 唤醒 + ASR + 编排 + 首字 + 全文生成，含网络往返；
对比对象为通用 API 直连（未做端侧裁剪与提示词瘦身）。
